# Correlation Plots for PNAS Study (10.1073/pnas.2218142120)

This repository contains the correlation plots generated in support of the analyses presented in the PNAS paper:

**[10.1073/pnas.2218142120](https://www.pnas.org/doi/epub/10.1073/pnas.2218142120)**

## Overview

The main goal of this repository is to provide visual materials used during the analysis phase of the study, with a focus on correlation structure across variables and conditions.

These plots complement the published results by documenting exploratory and supporting visual analyses.

## Contents

- **Correlation plots** used to inspect variable associations and trends relevant to the study.
- **Levelplots** generated during the analysis workflow (not included in the final publication).
- **NMR plots** produced as part of the broader data exploration and quality-check process (not included in the final publication).

## Relation to the paper

The published article reports the finalized analyses and figures.  
This repository archives additional visual outputs that helped guide interpretation and internal validation but were not selected for inclusion in the manuscript.

## Reproducibility notes

If scripts are included in this repository, they can be used to regenerate the plots from the processed data.  
Please refer to individual folders/scripts for dependencies, parameter settings, and plotting options.
